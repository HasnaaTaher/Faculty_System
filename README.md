# 🎓 Faculty System (OOP & SOLID Project in C++)

## 📌 Overview
This project is a simple **Faculty Management System** implemented in **C++**, designed to practice and apply **Object-Oriented Programming (OOP)** principles and **SOLID principles**.

The system simulates a university environment including:
- Students
- Doctors
- Courses
- Departments

---

## 🧠 Concepts Applied
- Classes & Objects
- Inheritance
- Abstraction (Pure Virtual Functions)
- Polymorphism
- Encapsulation
- Association between classes
- Basic SOLID principles

---

## 🏗️ System Structure
- **Person (Base Class)**
  - Student
  - Doctor

- **Course**
  - Represents academic courses

- **Department**
  - Manages students, doctors, and courses

- **Display Class**
  - Handles output display of system data

---

## ⚙️ Features
- Add students, doctors, and courses
- Assign courses to students and doctors
- Organize data inside departments
- Display full system details

---

## 💻 Technologies Used
- C++
- STL (vector, string)
- OOP Design Principles

---

## 🚀 Purpose of the Project
This project was built for learning purposes to strengthen understanding of:
- Object-Oriented Design
- Clean Code Structure
- SOLID Principles in practice
