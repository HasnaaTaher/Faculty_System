# 🎓 Faculty System (C++ OOP & SOLID + SQL Server)

## 📌 Overview
The C++ part focuses on object-oriented software design using OOP and SOLID principles, while the SQL Server part focuses on relational database design and SQL querying for the same domain.

The project models the core entities of a university including:
- Students
- Doctors
- Departments
- Courses
- Enrollments
- Teaching Assignments

The C++ part focuses on software design using OOP and SOLID principles, while the SQL Server part focuses on designing and querying a relational database for the same domain.

---

## 🏗️ Project Structure

### 📁 Part 1: C++ (OOP & SOLID)

Implements the university system using object-oriented design.

### Applied Concepts
- Classes & Objects
- Inheritance
- Encapsulation
- Abstraction
- Polymorphism
- Association
- SOLID Principles

### Main Classes
- Person
- Student
- Doctor
- Course
- Department
- Display

### Features
- Create students, doctors, departments and courses
- Enroll students in courses
- Assign doctors to courses
- Organize data inside departments
- Display complete system information
